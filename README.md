## About me

I work with **Java and JavaScript** across web applications, Android apps, desktop games, and Discord bots. My work includes personal repositories and team projects: an offline attendance app, a car-rental marketplace, a fashion e-commerce website, and board games with AI opponents.

I enjoy projects where the interface and the underlying logic matter equally: recording working hours, managing game turns, scheduling reminders, or organizing a shopping flow.

- **Web:** Java backends and interfaces built with HTML, CSS, and JavaScript.
- **Android:** Offline utilities and Firebase-backed apps with maps, chat, and booking flows.
- **Automation:** Discord slash commands, scheduled reminders, and mini games.
- **Learning:** Connecting application logic, data, and user experience through hands-on projects and AI board-game algorithms.

## Selected projects

### [Time Tracking App](https://github.com/NQThanh2/Time-Tracking-App)

An Android attendance app designed to work offline, with data stored locally on the device.

- Biometric check-in and check-out.
- Daily and monthly working-hour summaries.
- Salary calculation from an hourly rate, parking allowances, and attendance corrections.
- A calendar view for reviewing attendance.

**Stack:** Java / Android / SQLite / Gradle

### [O An Quan](https://github.com/NQThanh2/O-An-Quan)

A web implementation of the traditional Vietnamese board game, combining game rules with a Java backend and a browser interface.

- Local play and an AI game mode.
- Three AI difficulty settings: Easy, Medium, and Hard.
- A choice of who takes the first turn in AI games.
- REST endpoints for game state, moves, and move history, with WebSocket support in the project.

**Stack:** Java / Spring Boot / Thymeleaf / WebSocket / JPA / HTML / CSS / JavaScript

### [Discord Reminder & Mini Game Bot](https://github.com/NQThanh2/Bot-Discord)

A Discord bot for reminders, scheduled announcements, and lightweight games.

- One-time and daily reminders through slash commands.
- Scheduled announcements with server-management permission checks.
- Coin flips, dice, rock-paper-scissors, number guessing, and an 8-ball command.
- Reminder persistence using local JSON storage or Upstash Redis.

**Stack:** JavaScript / Node.js / discord.js / Redis

### [Re-Shop Web UI](https://github.com/NQThanh2/re-shop-web-ui)

A storefront interface with separate pages for browsing products and moving through a shopping flow.

- Home and shop pages.
- Product details, cart, and checkout interfaces.
- Login and contact pages.

**Stack:** HTML / CSS / JavaScript

### [CarVIA - Car & Driver Rental (LTMobile)](https://github.com/pvhNam/LTMobile)

A team-built Android marketplace for self-drive car rentals and rentals with a driver, with separate customer, driver, and admin flows.

- Vehicle listings, rental requests by day or trip, and pickup/destination selection on a map.
- Driver availability, trip acceptance, and trip progress management.
- Real-time chat, push notifications, favorites, and reviews.
- An internal wallet with VNPay sandbox top-ups, plus admin tools for users, listings, orders, and driver approvals.

**Stack:** Java / Android / Firebase / Cloud Functions / Cloudinary / Maps / VNPay Sandbox / Gradle

### [Fashion E-Commerce Website (ThucTapWeb)](https://github.com/pvhNam/ThucTapWeb)

A team-built fashion store using Java Servlet/JSP and MySQL, covering the customer shopping flow and store administration.

- Product search, category filters, color/size variants, reviews, cart, and vouchers.
- Google OAuth login, email OTP password recovery, and Vietnamese/English interfaces.
- Checkout with MoMo sandbox or cash on delivery, saved addresses, and order history.
- Admin tools for products, inventory, orders, users, news, and vouchers, with Excel revenue reports.

**Stack:** Java / Jakarta Servlet / JSP / JSTL / MySQL / HTML / CSS / JavaScript / Apache Tomcat / Gradle

### [Othello AI Game (DoAn_TTNT)](https://github.com/pvhNam/DoAn_TTNT)

A desktop Othello game from a team AI coursework project, combining an interactive Java Swing board with a computer opponent.

- Human-versus-computer play on an 8 x 8 board.
- Minimax search with a depth of five plies.
- Weighted board evaluation using position, mobility, and disc-count difference.
- Legal-move indicators, highlights for the latest move and flipped discs, live scores, and game restart controls.

**Stack:** Java / Swing / Minimax / Heuristic Evaluation / MVC

## How I work

I aim to make projects easy to understand, run, and improve.

- Start with a clear use case and a working version.
- Keep application logic separate from presentation where practical.
- Review important flows, including invalid input and unexpected states.
- Document setup steps and learn from each iteration.
